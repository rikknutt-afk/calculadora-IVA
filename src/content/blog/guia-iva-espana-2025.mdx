# Guía Completa del IVA en España 2025

El **Impuesto sobre el Valor Añadido (IVA)** es el principal tributo indirecto sobre el consumo en España y en la Unión Europea. Tanto si eres particular, autónomo o gestionas una pyme, dominar el cálculo del IVA es fundamental para emitir presupuestos precisos y cumplir con la Agencia Tributaria.

---

## 1. Tipos Impositivos del IVA en España

En España conviven tres tipos impositivos estándar regulados por la Ley 37/1992 del IVA:

### 🎯 Tipo General (21%)
Es el tipo impositivo por defecto aplicable a la mayoría de operaciones comerciales:
- Servicios profesionales (abogados, consultores, desarrolladores)
- Tecnología, informática y electrodomésticos
- Ropa, calzado y textil
- Vehículos nuevos y usados

### 🍞 Tipo Reducido (10%)
Se aplica a bienes y servicios de consumo habitual o fomento social:
- Alimentación general (excepto productos básicos)
- Hostelería, restaurantes y servicios de alojamiento
- Transporte de viajeros y equipajes
- Obras de renovación y construcción de vivienda

### 💊 Tipo Superreducido (4%)
Reservado para bienes y servicios de primera necesidad:
- Pan, leche, huevos, frutas y verduras
- Medicamentos para uso humano
- Libros, periódicos y revistas
- Prótesis y vehículos para personas con movilidad reducida

## 2. Fórmulas Matemáticas para el Cálculo del IVA

Calcular el IVA requiere dos operaciones fundamentales: **añadir IVA** (a partir de una base imponible) o **desglosar IVA** (a partir de un precio final).

### Fórmula para Añadir IVA (Base a Total)
```text
Cuota IVA = Base Imponible × (Tipo IVA / 100)
Total = Base Imponible + Cuota IVA = Base Imponible × (1 + Tipo IVA / 100)
```

*Ejemplo:* Para una base de 100 € con 21% de IVA:
```text
100 × 1,21 = 121 €
```

### Fórmula para Quitar / Desglosar IVA (Total a Base)
```text
Base Imponible = Precio con IVA / (1 + Tipo IVA / 100)
Cuota IVA = Precio con IVA - Base Imponible
```

*Ejemplo:* Para un producto de 121 € con 21% de IVA:
```text
Base = 121 / 1,21 = 100 €
Cuota IVA = 121 - 100 = 21 €
```
